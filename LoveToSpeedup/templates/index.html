核心接口示例

POST /api/acquire —— 获取临时代理
curl -s -X POST http://<网关地址>/api/acquire \ -H "X-API-Key: <登录密码>" -H "Content-Type: application/json" \ -d '{"region":"上海","ttl":120}' 复制
GET/POST /api/extract —— 提取式（代理池采集器友好）
curl "http://<网关地址>/api/extract?region=上海&ttl=120&key=<登录密码>" # 纯文本响应: # 116.128.189.42:10802 /api/extract?region=上海&ttl=120&key=<登录密码>\"')">复制
POST /api/slots —— 创建长期在线端口槽
curl -s -X POST http://<网关地址>/api/slots \ -H "X-API-Key: <登录密码>" -H "Content-Type: application/json" \ -d '{"account_id":"1788727900001","region":"江苏","mode":"long"}' 复制
代理使用方式
export http_proxy=http://<网关IP>:<代理端口> export https_proxy=http://<网关IP>:<代理端口> curl http://ip.3322.net 复制

项目介绍

爱加速代理网关（LoveToSpeedup）是一个基于爱加速国内节点的 HTTP 代理网关服务。它把爱加速客户端封装为可远程调用的 HTTP 代理，支持多账户、多端口并行：主端口固定，额外端口槽可把不同账户绑定到不同对外端口，适合给宿主机及其他 Docker 任务提供短期或长期代理。

核心能力：按地区获取临时代理、租约到期自动断开、端口槽掉线自连、账户互斥校验（避免单账户单代理冲突）、以及面板改密（即 API Key 同步）。

短期（short）vs 长期（long）：两者都是端口槽，区别在于是否持久保活。 短期 带 TTL，连接达到有效期后自动断开，且不会被后台保活； 长期 常驻在线，由守护线程每 10 秒巡检，一旦掉线会自动重连、永不超时。简单说：长期槽＝掉线自连、持续在线，短期槽＝用完到期自动释放。

项目地址：https://github.com/hanx11192-ship-it/LoveToSpeedup
